# 操作说明

## 账号与聊天身份

管理员在“设置”维护内部账号，可搜索、筛选、编辑、删除和恢复。账号密码至少 12 位，编辑时留空表示保持原密码。修改用户名、角色或密码会撤销旧会话；不能删除当前登录账号或修改自己的角色，系统至少保留一名可用管理员。

发送人按内部账号的用户名或显示姓名精确匹配客服，未匹配者按客户处理。新账号自动获得默认内部记录范围，无需管理客户或聊天群。历史数据的所有者、权限范围和身份映射继续用于访问隔离及证据追溯。

## 导入并生成草稿

1. 在“聊天记录”上传 `.txt` / `.md` 文件。最大 10 MiB、20,000 条消息，支持 UTF-8、GB18030、UTF-16 自动识别。可先用 [合成聊天样本](../examples/chat-demo.txt) 体验。
2. 查看解析预览、警告、保留数量和过滤原因。警告可分页展开并定位原文，检查后明确勾选接受。
3. 点击“确认导入并生成草稿”；需要时展开选项调整本地 / 外部配置及工单 / QA 类型，也可“仅导入”。外部配置会将相关原文发送到该服务，失败不会自动切换配置。
4. 页面进入文件，定时显示任务进度和生成记录。点击“核对草稿”进入具体版本，返回后仍停留在当前文件。任务成功仅表示处理完成，草稿仍需审核。

同一文件重复上传会打开已有导入记录，不覆盖人工处理。文件名相同但内容不同会分别保留。导入已成功而生成失败时，可直接重试生成；已有任务可取消或从断点继续，成功步骤和历史结果保留。

文件列表可按文件名及导入状态筛选。打开文件后，可按发送人、关键词和归属状态搜索消息；列表按每页 10 条展示，原文与来源位置保持可追溯。

## 预筛选与消息归属

预筛选仅排除确定的空白、纯媒体占位、明确导出系统通知，以及缺少邻近业务上下文的完整问候或致谢。短状态、SQL、引用、解析警告和未知内容均保留。新规则不会自动重判旧导入，重复上传也不会覆盖原有恢复结果。

预览及文件列表显示总数、保留、过滤、已恢复和过滤原因。已确认文件中的过滤消息可逐条“恢复为待处理”；恢复后需重新启动整理生成。原始文件、原文和历史过滤原因保留。统计只描述导入预筛选，不混入后续 AI 或人工忽略决定。

可勾选消息创建问题或追加到已有问题，并指定提问、回答、跟进、纠正、上下文。同一问题可跨天、跨文件持续追加，一条消息可关联多个问题。人工归属完成后可打开对应工单。翻页或更换筛选会清空勾选，批量部分失败会报告已处理数量并刷新。

“已忽略”仍保留原文。管理员可通过 API 预览或应用规则重评，但规则不会覆盖人工明确忽略的选择；接口说明见[中文 API 指南](api-guide.zh-CN.md)。

## 编辑与原文依据

工单填写标题、问题、过程、当前结论和处理状态。日期根据有效来源建议，必要时展开校正日期依据；所有时间无效时阻止保存。没有原始提问的工单在批准前还需要明确确认。已保存版本使用自身日期快照。

问题、回答、结论和关键事实旁的原文入口可打开来源面板。选中文字或整条消息即可引用；重复引文需要确定位置。系统按 Unicode 码点保存片段，保留换行和表情。已删除来源可查看历史，但不可新增引用。

工单审核至少需要整张记录的有效原文依据，每条关键事实还须有支持证据。QA 按问题、回答、关键事实与贡献者逐项校验；缺少明确答案、关键事实或核心贡献者不能批准。贡献者必须有本人直接回答的证据，引用他人文字不能计入。系统给出的贡献者建议需要人工点击采用。

## 保存与审核

“保存并提交审核”先保存不可变新版本，再提交该确切版本；未修改的草稿直接提交，也可单独保存。保存失败不会提交，提交校验失败会保留已保存草稿，修正后可重试。

审核员或管理员明确批准或驳回，驳回必须填写原因。批准后切换正式版本，旧版本、审核操作者和意见仍可查看。工单业务状态与审核状态独立，“已回答”不会自动变为“已解决”。

相关来源仍有未归属或待人工判断消息时，需先完成归属或明确忽略。来源新增、重新归属、删除恢复或发送人身份变化可能使旧草稿失效，需重新保存后提交。并发编辑和审核通过版本校验保护。

离开未保存正文或尚未提交意见时会提示。审核意见和内部备注在本次登录期间按账号、记录、版本临时保存；刷新页面后不保证恢复，须通过对应操作写入系统。请求失败保留输入。

## 删除、恢复与追溯

聊天消息、导入文件、整张工单和 QA 由管理员删除或恢复。草稿、驳回稿、待审核稿可由管理员或该版本创建者操作，AI 草稿归属于发起任务的用户。正式和历史版本不能作为草稿删除。

删除需确认，采用可恢复标记并保留审计。管理员可在已删除范围查看和恢复；恢复文件内消息前需要先恢复所属文件。预筛选恢复与删除恢复是两个不同入口。

AI 任务及文件进度显示最后成功更新时间，自动刷新失败会提示并提供重试。任务生成记录、具体修订、原文、证据和审核历史均可继续追溯。
